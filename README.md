# Daya Boutique — Site vitrine

Site statique de la boutique Daya, prêt à déployer sur Vercel (ou Netlify, GitHub Pages...). Aucun build requis : HTML/CSS/JS purs.

## Déploiement sur Vercel

1. Allez sur https://vercel.com et connectez-vous avec GitHub
2. "Add New Project" → importer ce repository
3. Vercel détecte automatiquement un site statique → "Deploy"
4. L'URL obtenue : `https://daya-boutique.vercel.app` (personnalisable dans Settings → Domains)

## Structure

- `index.html` — la page complète
- `images/` — visuels du site

## Pour modifier

- Produits et prix : section `#selection` dans `index.html`
- Numéro WhatsApp : remplacer `213794031309` partout par le vrai numéro de la boutique
- Téléphone et adresse : section `#contact`
